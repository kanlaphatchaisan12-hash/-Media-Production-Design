ภาพรวมจาก Class Summary

What to say คือเรื่องและสารที่อยากสื่อ ส่วน How to say คือวิธีออกแบบการนำเสนอให้ผู้ชมเห็น ได้ยิน และรู้สึกตามเป้าหมาย งานออกแบบที่ดีมีทั้ง Form (รูปแบบที่ผู้ชมรับรู้) และ Function (หน้าที่ที่ต้องทำให้สำเร็จ)

รู้จักผู้ชม›หา Insight›Big Idea + Concept›Format + Content›ออกแบบประสบการณ์

คิดงานในช่วง pre-production ให้เห็นภาพล่วงหน้า ใช้เป้าหมายเดียวกันคุยกับทีม และคุมข้อจำกัดด้านเวลา งบ คน อุปกรณ์ และทักษะ ภาพ เสียง และจังหวะตัดต่อมีหน้าที่ช่วยเล่าเรื่องให้ชัดและลื่นไหล

ผู้ชมและเนื้อหา

Content + Audience Analysis

  • ใครคือคนดูแยกคนที่ดูจริงออกจากกลุ่มหลักที่ตั้งใจทำรายการให้
  • เขาดูเพราะอะไรพฤติกรรมบอกว่าทำอะไร ส่วน Insight บอกว่าทำไม
  • จำ 5 แกนข้อมูลพื้นฐาน · ความคิด · คุณค่า · แรงจูงใจ · วิถีชีวิต
  • จากไอเดียสู่ตอนจริงBig Idea คือแกนคิด, Concept คือภาพรวมรายการ, Format คือโครงที่ใช้ซ้ำ, Content คือเรื่องในแต่ละตอน

ตัวอย่าง นักศึกษาดูคลิปทำอาหารสั้น ๆ เป็น พฤติกรรม ถ้าพบว่าพวกเขาอยากประหยัดแต่มีเวลาน้อย นั่นคือ Insight ที่นำไปทำรายการ “มื้อเย็น 15 นาที” ได้

อ่านรายละเอียดและเปิดสไลด์อ้างอิง

Segmentation แบ่งผู้ชมเป็นกลุ่มที่มีลักษณะร่วมกัน Target คือกลุ่มที่รายการตั้งใจสื่อสารด้วย และ Insight อธิบายเหตุผลหรือแรงขับเบื้องหลังพฤติกรรม

Audience คือคนที่รับชมจริง ส่วน Primary target คือกลุ่มหลักที่ควรมีน้ำหนักที่สุดต่อการออกแบบ Secondary target คือกลุ่มรองที่น่าจะสนใจเช่นกัน

แกนวิเคราะห์ผู้ชม 5 ด้าน

Demographic
ข้อมูลพื้นฐาน เช่น อายุ อาชีพ รายได้ การศึกษา และพื้นที่
Psychographic
แนวคิด ทัศนคติ และความเชื่อที่มีผลต่อการตัดสินใจ
Value
คุณค่าที่ผู้ชมให้ความสำคัญ เช่น อิสระ ความมั่นคง หรือความยั่งยืน
Motivation & Aspiration
แรงผลักดันและสิ่งที่อยากบรรลุ เช่น อยากประหยัด อยากแก้ปัญหา หรืออยากพัฒนาตัวเอง
Lifestyle & Interests
ชีวิตประจำวัน กิจกรรม และความสนใจ เช่น การกิน การเที่ยว และการออกกำลังกาย

เสริมด้วย media behavior ว่าดูอะไร เมื่อไร ที่ไหน เพราะอะไร และดูอย่างไร จากนั้นใช้ persona สร้างตัวแทนผู้ชมจากรูปแบบที่เห็นในข้อมูล เพื่อให้ทีมตัดสินใจเรื่องภาษา พิธีกร จังหวะ กราฟิก และแพลตฟอร์มได้สอดคล้องกัน

จาก Insight ไปเป็นรายการ

Creative Opportunity
โอกาสทำเนื้อหาที่ตอบความต้องการหรือปัญหาของผู้ชม
Big Idea
แนวคิดแกนที่ชัด ตรงกับผู้ชม มีมุมเฉพาะ และต่อยอดเป็นหลายตอนได้
Concept
ภาพรวมว่ารายการเกี่ยวกับใคร เกิดอะไร นำเสนออย่างไร และผู้ชมได้ประสบการณ์อะไร
Genre / Format
Genre คือประเภท เช่น game show ส่วน Format คือระบบที่ทำซ้ำได้ เช่น บทบาท เป้าหมาย กติกา ลำดับช่วง วิธีตัดสิน และจังหวะเฉลย
Mechanic / Content
Mechanic คือวิธีเฉพาะที่ขับ Format เช่น จับฉลากหรือโหวต ส่วน Content คือเรื่องและรายละเอียดในตอนนั้น
Proposal
เอกสารที่เชื่อมผู้ชมและ Insight เข้ากับ Big Idea, Concept, รูปแบบ, เนื้อหา, ภาพ และผู้สนับสนุน เพื่อให้เห็นเหตุผลของรายการทั้งระบบ

เช็กตัวเอง · “ผู้ชมดูคลิปสั้นระหว่างเดินทาง” เป็น Insight แล้วหรือยัง?

เป็นข้อมูลพฤติกรรม ลองหาข้อมูลต่อว่าเหตุใดจึงเลือกคลิปสั้น เช่น ต้องการติดตามเรื่องสำคัญแต่มีเวลาต่อเนื่องน้อย เมื่อมีหลักฐานรองรับ เหตุผลนี้จึงใช้พัฒนา Insight ได้

อารมณ์และงานภาพ

Mood & Tone, Mood Board + Graphics

  • Moodอยากให้คนดูรู้สึกอย่างไร เช่น อบอุ่น
  • Toneใช้วิธีอะไรสร้างความรู้สึกนั้น เช่น แสงอุ่นและกล้องเคลื่อนช้า
  • Mood Boardรวมตัวอย่างสี ตัวอักษร ภาพ และพื้นผิวให้ทั้งทีมเห็นภาพเดียวกัน
  • Graphicsเลือกขนาด ตำแหน่ง และสีให้คนดูรู้ว่าควรอ่านหรือมองอะไรก่อน

ตัวอย่าง ถ้ารายการอาหารอยากให้คนดูรู้สึก อบอุ่น ให้ลองใช้แสงนุ่ม พื้นผิวไม้ และสีครีม เปิดรายละเอียดเพื่อทบทวนว่าโครงสีแต่ละแบบเลือกอย่างไร

อ่านรายละเอียดและเปิดสไลด์อ้างอิง
Mood
อารมณ์เป้าหมาย เช่น อบอุ่น ตื่นเต้น อึดอัด กำหนดได้ตั้งแต่ทั้งรายการจนถึงแต่ละฉากหรือช็อต
Tone
วิธีและเทคนิคที่ทำให้เกิดอารมณ์นั้น เช่น ใช้ไฟอุ่นนุ่ม ผิวไม้ และการเคลื่อนกล้องช้าเพื่อสร้างความอบอุ่น
Mood Board
ภาพรวบรวมสไตล์ สี ตัวอักษร วัสดุ และพื้นผิว ช่วยให้ทีมเห็นทิศทางเดียวกันและใช้ตรวจงานกราฟิก ฉาก เสื้อผ้า และแสง
Art Direction
คุมองค์ประกอบศิลป์ให้มีเอกภาพและสร้างความหมาย เช่น จัดลำดับสิ่งที่ควรมองก่อน รวมหัวข้อที่เกี่ยวกัน และเล่าความสัมพันธ์ผ่านตำแหน่ง

ลำดับทำ Mood Board

เริ่มจาก Concept → โครงสีและสัดส่วน → องค์ประกอบหลักและสไตล์หรือยุค → ผ้า เสื้อผ้า และเครื่องประดับ → ตัวอักษร → พื้นผิว → จัดวางและถ่วงน้ำหนัก

Digital board ทำงานร่วมกันง่ายและปรับสีได้แม่น ส่วน Analog board ถ่ายทอดผิวสัมผัสและลักษณะวัสดุจริงได้ดี

Color Scheme และ Graphics

Hue / Saturation / Value
เฉดสี / ความอิ่มสี / ความอ่อน–เข้มของสี ใช้กำหนดบทบาทของสีและความเด่นในภาพ
Monochrome / Analogous
เฉดเดียวปรับความอิ่มหรือความอ่อน–เข้ม / สีข้างกันบนวงจรสี
Complementary
สองสีตรงข้าม ช่วยเพิ่มความตัดกัน ควรกำหนดบทบาทและสัดส่วนสี
Triadic / Tetradic
สามสีห่างเท่ากัน / สี่สีจากคู่ตรงข้ามสองคู่ แบบสี่สีควรเลือกสีหลักช่วยคุมภาพรวม
Visual Hierarchy
ใช้ขนาด ตำแหน่ง น้ำหนัก สี และ contrast ให้คนดูเข้าใจว่าอะไรสำคัญก่อน เช่น หัวเรื่อง ชื่อแขก และข้อความรอง

โครงสีเริ่มจากวงจรสี วรรณะร้อน–เย็น อารมณ์ หรือรสนิยมตาม Concept ก็ได้ ภาพเคลื่อนไหว ต้องคิดองค์ประกอบตลอด lead-in → body → lead-out เพราะตำแหน่งวัตถุและกล้องเปลี่ยนระหว่างช็อตได้

เช็กตัวเอง · “อยากให้คนดูลุ้น” กับ “ใช้แสงแข็งและคอนทราสต์สูง” ต่างกันอย่างไร?

“ลุ้น” คือ Mood ส่วนแสงแข็งและคอนทราสต์สูงเป็นเทคนิคใน Tone ที่ใช้สร้างความรู้สึกนั้น

ฉากและเวที

Set + Stage Design

  • Location / SetLocation คือสถานที่ถ่ายจริง ส่วน Set คือฉากที่จัดหรือสร้างขึ้น
  • Set Prop / Hand Propของตกแต่งฉาก กับของที่ผู้แสดงหยิบจับหรือใช้งาน
  • Blocking / ZoningBlocking วางตำแหน่งผู้แสดง ส่วน Zoning แบ่งพื้นที่ตามหน้าที่
  • ก่อนลงมือสร้างเช็กว่าฉากรับน้ำหนักได้ คนเดินสะดวก และกล้องถ่ายได้ตามมุมที่วางไว้

ตัวอย่าง ครัวที่เช่าคือ Location เคาน์เตอร์ที่สร้างเพิ่มคือ Set หม้อที่พิธีกรหยิบใช้คือ Hand Prop

อ่านรายละเอียดและเปิดสไลด์อ้างอิง

เวทีคือพื้นที่สื่อสาร ต้องคิดว่าผู้ชมเห็นอะไรในเฟรม นักแสดงเคลื่อนไหวอย่างไร และทีมถ่ายทำทำงานอย่างปลอดภัยหรือไม่

Location
สถานที่ถ่ายทำจริง ให้ Location Manager สำรวจเรื่องเสียง แสง เวลาเข้า–ออก การอนุญาตและเงื่อนไขเช่า พร้อมทำ floorplan หรือ stage plan
Set / Stage
สภาพแวดล้อมที่จัดหรือสร้างขึ้น จะสร้างเสริมใน Location หรือสร้างในสตูดิโอก็ได้ ต้องรองรับการแสดง กล้อง และอุปกรณ์
Set Prop / Hand Prop
ของที่วางเพื่อแต่งและเล่าเรื่องในฉาก / ของที่นักแสดงหรือผู้ร่วมรายการหยิบจับใช้ Prop Master ทำรายการแยกตามฉาก
Breakdown Sheet
แยกสิ่งที่ต้องใช้จากบท เช่น คิว สถานที่ วัน/คืน ภายใน/ภายนอก นักแสดง เครื่องแต่งกาย และพร็อพ ตาม Class Summary อยู่ในความรับผิดชอบของ 1st AD
Fitting / Continuity
ลองเสื้อผ้า หน้า ผมกับผู้แสดงจริง แล้วถ่ายรูปอ้างอิงเพื่อรักษาความต่อเนื่อง พิจารณาการแพ้ ข้อจำกัดของชุด และแสงจริงด้วย

เช็กก่อนสร้างฉาก

  • Functional zoning: แบ่งพื้นที่พิธีกร แขก กิจกรรม จอ คนดู ทางเข้า–ออก และกล้องหรือทีมเทคนิคตามรูปแบบรายการ
  • กล้องและความลึก: วางมุม wide/medium/close-up และทางเคลื่อนกล้อง แยก foreground, midground, background ด้วยตำแหน่ง แสง สี และมิติ
  • เทคนิคและการใช้งาน: ตรวจความปลอดภัย น้ำหนักสูงสุด ทัศนวิสัย การเปลี่ยนฉาก การติดตั้ง และการเชื่อมระบบ ฉากที่ใช้ซ้ำควรถอดประกอบได้และใช้วัสดุเหมาะกับอายุงาน
  • จัดหาพร็อพ: สร้าง ซื้อ ยืม หรือเช่า ถ่ายภาพเทียบสเกลเมื่อส่งงาน คิดเรื่องประกันของมูลค่าสูงและลดของเสียด้วยหลัก 3R

Mise-en-scène คือการจัดองค์ประกอบในฉากเพื่อสื่อความหมาย เช่น Set, Prop, แสง, พื้นที่ว่าง, องค์ประกอบภาพ, Costume, Makeup, การแสดง, ลักษณะภาพ และ Blocking หรือตำแหน่งและการเคลื่อนไหวของนักแสดงสัมพันธ์กับกล้องและแสง

สปอนเซอร์และแบรนด์

Sponsor + Brand Integration

  • เริ่มจาก Program Valueดูว่าคนดู เนื้อหา และประสบการณ์ของรายการมีอะไรที่แบรนด์ร่วมสร้างได้
  • Visibility / Placementเห็นโลโก้ = Visibility เห็นตัวสินค้าอยู่ในฉาก = Placement
  • Usage / Content Integrationใช้สินค้าจริง = Usage ถ้าสินค้ามีบทบาทต่อโจทย์หรือช่วงรายการ = Content Integration
  • Branded Experienceแบรนด์ช่วยให้เกิดกิจกรรม รางวัล หรือประสบการณ์ที่คนดูเข้าร่วมได้

ตัวอย่าง เครื่องปั่นวางบนโต๊ะคือ Placement พิธีกรเปิดใช้คือ Usage โจทย์แข่งที่ต้องใช้ฟังก์ชันเฉพาะคือ Content Integration

Sponsor สนับสนุนได้ทั้งเงิน สินค้า บริการ สถานที่ เทคโนโลยี หรือสิทธิ์เข้าถึง แลกกับคุณค่าที่เกิดกับแบรนด์และผู้ชม Advertising โดยทั่วไปซื้อพื้นที่หรือเวลาเพื่อส่งสารแบรนด์ ส่วน Sponsorship เชื่อมแบรนด์เข้ากับบริบทของรายการและประสบการณ์ของคนดู

Visibility
เห็นชื่อหรือโลโก้ เช่น ป้ายหรือเครดิตท้ายรายการ
Product Placement
สินค้าอยู่ในฉาก เช่น เครื่องปั่นบนโต๊ะ โดยไม่มีการใช้งานในช็อตนั้น คิดมุมกล้อง ระยะเวลาที่เห็น และเหตุผลที่สินค้าควรอยู่ตรงนั้น
Product Usage
พิธีกรหรือผู้ร่วมรายการใช้สินค้าจริง เช่น ใช้เครื่องปั่นทำสมูทตี้
Content Integration
แบรนด์หรือสินค้ามีบทบาทต่อช่วงรายการ เรื่อง หรือกติกา เช่น โจทย์แข่งที่ต้องใช้ฟังก์ชันเฉพาะของเครื่องปั่น
Branded Experience
แบรนด์ทำให้เกิดประสบการณ์ กิจกรรม รางวัล หรือสิทธิ์เข้าถึง เช่น เวิร์กช็อปสำหรับผู้ชมที่แบรนด์สนับสนุน

เวลาพิจารณาความเหมาะสม ให้ดู ผู้ชม เนื้อหาและค่านิยม และ บทบาทที่เข้ากับตรรกะรายการ ประสบการณ์ผู้ชมและความน่าเชื่อถือของรายการเป็นเกณฑ์สำคัญ

จริยธรรมและกฎหมาย

Ethics + Laws

  • ลิขสิทธิ์ถ้าเป็นเพลง ภาพ หรือคลิปของคนอื่น ให้ตรวจสิทธิและเงื่อนไขการใช้
  • PDPAถ้าภาพ เสียง ชื่อ หรือข้อมูลประกอบระบุตัวคนได้ ให้พิจารณาสิทธิและเหตุผลที่ต้องเปิดเผย
  • หมิ่นประมาทถ้าโจทย์มีการกล่าวหาคนอื่นต่อบุคคลที่สาม ให้คิดถึงผลต่อชื่อเสียง
  • เด็กและเยาวชนถ้าโจทย์เกี่ยวกับเด็กผู้เสียหาย ให้ดูว่าข้อมูลใดอาจเปิดเผยตัวเด็ก รวมถึงโรงเรียนหรือเสียง

ตัวอย่าง คลิปเดียวอาจต้องตรวจหลายเรื่อง เช่น สิทธิใช้เพลง และ การเปิดเผยตัวเด็ก เป็นคนละประเด็น

อ่านรายละเอียดและเปิดสไลด์อ้างอิง

จริยธรรมสื่อ เน้นตรวจสอบข้อเท็จจริง แยกความเห็นจากข้อเท็จจริง เปิดโอกาสให้ชี้แจง แก้ไขเมื่อผิด เคารพสิทธิและศักดิ์ศรี และรักษาความเป็นอิสระจากผลประโยชน์ของผู้สนับสนุน

4 เรื่องที่ Class Summary ระบุ

Copyright · ลิขสิทธิ์
รูป เพลง คลิป และงานสร้างสรรค์ต้องตรวจเจ้าของสิทธิและเงื่อนไขอนุญาต เช่น ช่องทางเผยแพร่ การใช้เชิงพาณิชย์ อายุสิทธิ และการดัดแปลง การให้เครดิตเพียงอย่างเดียวไม่ทำให้ใช้ได้ทุกกรณี ข้อยกเว้นต้องพิจารณาตามเงื่อนไข
PDPA · ข้อมูลส่วนบุคคล
ข้อมูลที่ระบุตัวบุคคลได้โดยตรงหรือทางอ้อม เช่น ชื่อ ใบหน้า เสียง และข้อมูลประกอบ ต้องแยกวัตถุประสงค์การถ่าย การเก็บ และการเผยแพร่ สไลด์ชวนคิดถึงฐานที่ใช้และการเปิดเผยเท่าที่จำเป็น
Defamation · หมิ่นประมาท
คิดเรื่องการใส่ความผู้อื่นต่อบุคคลที่สามซึ่งอาจทำให้เสียชื่อเสียง ถูกดูหมิ่น หรือถูกเกลียดชัง หากเผยแพร่ผ่านสื่อให้แยกประเด็นการโฆษณาตามที่สไลด์อธิบาย
เด็กและเยาวชน
ในโจทย์เด็กผู้เสียหายหรือเด็กที่เกี่ยวข้องกับคดี ให้คิดถึงประโยชน์ของเด็กและข้อมูลที่ระบุตัวได้ เช่น ชื่อ โรงเรียน บ้าน เสียง และรายละเอียดประกอบ แม้เบลอหน้าแล้วก็อาจยังรู้ว่าเป็นใคร
